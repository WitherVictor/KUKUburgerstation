# 弹壳模具 "---", "-S-", "-C-", S = 钢板 C = 钢丝钳 也许还有其他配方使用相似的摆放方式？ # 弹壳 用弹壳模具熔铸黄铜，可以制成30个弹壳 # 黄铜 2个铜锭、1个锌锭，产出3个黄铜锭 # 从子弹中回收火药 把子弹放在弹药压制机中排的中间格子里，旁边放上钢丝钳，就应该能安全取出一包火药。 # 制作子弹？ " P ", " GM", " C ", P = 弹丸 G = 火药 C = 弹壳 M = 待填装的弹匣 看来只要把棒材用钢丝钳剪成弹丸，再配上火药和备用弹壳，就能自制弹药！ 似乎不是每种组合都有效，但我发现镁能做燃烧弹，塑钢能做优质弹药！ 需要准备与弹匣容量相等数量的弹壳。还要记住，优质弹药补给机不能补充非标准类型的弹药。 这样看来，花钱买贫铀独头弹就不划算了。如果只想做单发弹药，例如霰弹枪用的弹药，就把空弹匣换成一发基础弹药。 不需要额外的火药或弹壳！如果制作失败，但我确定配方没错，就该检查弹匣是不是空的……
